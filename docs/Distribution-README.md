# ClipContext 0.1.1

ClipContext 是基于 Maccy 的 macOS 剪贴板管理应用，提供历史搜索、收藏板、富文本与纯文本粘贴、顺序粘贴，以及由你控制的云盘共享和 Agent 读取。

## 使用与反馈

- [使用说明](使用说明.md)：安装、日常操作、快捷键、隐私设置、Google Drive、iCloud、MCP 和简报。
- [Bug 反馈说明](<Bug 反馈说明.md>)：排查步骤、反馈入口和可以直接复制填写的问题模板。
- [简明 HTML 指南](ClipContext-Guide.html)：快速查看云盘和 Agent 配置。

这两份 Markdown 也放在发行 ZIP 的根目录，解压后即可查看。此处的链接指向应用内部副本，移动或安装应用后仍可使用。

共享默认关闭。直接粘贴和顺序粘贴需要 macOS 辅助功能授权；未授权时仍可复制内容后手动按 `⌘V` 粘贴。云盘保存的是共享目录的单向快照，不会自动恢复或合并本地剪贴板历史。
