MACOS · 使用与操作

把复制过的内容
找回来，再用一次。

从日常复制、搜索和收藏，到把选定资料交给 Agent。本手册列出当前版本的全部操作入口，并说明哪些能力需要额外授权或尚未提供。

1

正常复制

保持 ClipContext 运行，在任意应用中复制一段文字、图片，或在 Finder 复制文件。

2

打开历史

点菜单栏图标，或按默认快捷键 ⌘⇧C。浏览卡片，也可以点放大镜搜索。卡片面板里的新增菜单目前仍为中文。

3

选中，再粘贴

点一张卡片或按 Return 复制它，然后回到目标应用按 ⌘V。

默认是“复制回剪贴板”。 若要直接粘到原应用，可用 ⌥Return 或卡片右键 → 粘贴，并先授予 macOS 辅助功能权限。设置 → General（通用）可更改默认行为。

界面语言说明：当前安装版跟随系统英文，设置左栏显示 General（通用）、Agent、Privacy（隐私）、Shortcuts（快捷键）、Appearance（外观）、Advanced（高级）；卡片和 Agent 新功能仍显示中文。本手册在主要设置路径中提供中英对照。

日常采集与取用

12 项
U01打开与关闭历史

点菜单栏图标，或默认按 ⌘⇧C 打开；Esc 或点击面板外关闭。

说明：默认是屏幕底部卡片视图；打开快捷键可在设置中更换。

U02自动保存复制内容

保持应用运行，在其他 App 正常复制文字、富文本、图片，或在 Finder 复制文件。

说明：默认每 0.5 秒检查剪贴板；不会读取启动前未发生变化的现有剪贴板。文件保存引用，不能当作文件内容备份。

U03浏览卡片

左右滚动底部横向列表；按左右方向键切换卡片。

说明：空搜索时可用左右方向键选卡；输入查询后，左右键用于编辑搜索词。输入法候选词出现时，先完成文字输入。

U04复制历史内容

单选状态点击卡片/列表条目或按 Return；随后在目标应用按 ⌘V。

说明：默认仅复制回系统剪贴板。多选状态点击会增减选择，Return 会准备顺序粘贴队列；右键菜单仍可单独复制。

U05直接粘贴到原应用需系统授权

单选状态选条目按 ⌥Return、⌥点击，或卡片右键 → 粘贴。

说明：需 macOS 辅助功能授权。缺权限时会弹出说明，可点打开系统设置并由你完成授权；稍后仍可手动 ⌘V，授权后需重新发起操作。

U06粘贴为纯文本需额外接入

默认设置下按 ⌥⇧Return、⌥⇧点击；或卡片右键 → 粘贴为纯文本。

说明：仅有纯文本表示时可去格式；卡片右键在无纯文本时禁用该操作。修改默认粘贴/去格式选项后修饰键映射会变化。

U07数字与字母快捷取用

打开面板后按条目显示的修饰键 + 数字/字母。

说明：普通历史为数字快捷键；置顶收藏有固定字母快捷键。卡片仅在按修饰键时展示提示。

U08重复复制与排序

正常再次复制同一内容后查看最近记录或次数。

说明：支持最近复制时间与复制次数排序。0.1.1 已调整富文本回写表示的去重比较，保留原收藏和不同格式；本轮回归与实机验证状态以交付报告为准。

U09内容预览

卡片右键 → 预览，或选中条目按 ⌃Space；列表视图可点击预览侧栏按钮。

说明：预览提供全文或图片，以及来源、首次/最近复制时间、复制次数；卡片预览是固定尺寸弹出框，列表是侧栏。

U10链接与文件卡片

复制完整 http/https URL 会显示链接卡片；Finder 文件显示文件名与类型图标。

说明：链接卡片是域名/路径加通用浏览器图标，不会抓取网页封面或读取网页正文；文件卡片也不上传原文件。

U11图片与颜色预览

复制图片查看缩略图/尺寸；复制十六进制颜色值可显示色块。

说明：色块和来源应用图标可在外观中开关。

U12图片文字复制

切换列表视图，选中有可识别文字的图片，打开预览侧栏，点文字识别图标。

说明：该按钮复制已有识别文本，未识别出文字时禁用。卡片预览没有此工具条，当前需走列表入口。

搜索与筛选

6 项
U13展开搜索

点击卡片顶部放大镜，输入关键词；清除按钮恢复全部匹配项。

说明：卡片起始为收起式搜索；搜索时收藏板文字收为图标。

U14按类型筛选

展开搜索，点右侧筛选按钮，选全部类型、文本、链接、图像或文件。

说明：筛选与当前剪贴板/收藏/收藏板范围共同生效。

U15选择搜索方式

设置 → 通用（General） → 搜索，选精确、模糊、正则或混合。

说明：精确搜索为不区分大小写的子串匹配，实际搜索条目的标题（可能为别名/图片识别文字），不是所有附件原始数据。

U16匹配结果与空结果

输入不存在的关键词查看未找到匹配内容；清除或换词恢复结果。

说明：搜索与内容类型、当前收藏板共同决定结果。未找到时先清空关键词、再把类型恢复为全部。

U17匹配样式

设置 → 外观（Appearance） → 匹配文本高亮，选粗体、斜体、下划线或颜色。

说明：纯文本卡片与列表使用匹配标题显示；不是网页内容高亮。

U18搜索编辑快捷键

⌃U 清空搜索；⌃H 删除最后一个字符；⌃W 删除最后一词。

说明：输入法候选词出现时按键处理会避让组合输入。

收藏、收藏板与内容编辑

10 项
U19收藏与取消收藏

卡片右键 → 收藏/取消收藏，或选中后按 ⌥P；点击顶部收藏标签查看。

说明：内置「收藏」对应置顶功能，保存固定快捷键；它与自己创建的收藏板是两套整理方式。

U20新建收藏板

点顶部 ＋，输入非空名称并保存。

说明：新板会被选中，默认颜色按创建顺序分配；展开搜索时 ＋ 隐藏。

U21加入或移出收藏板

先创建板，再右键卡片 → 加入收藏板 → 点目标板；再次点击已打勾的板即可移出。

说明：同一条内容可以放进多个板。加入自定义板不会同时加入内置「收藏」，也不会单凭此操作自动共享给 Agent。

U22收藏板重命名与颜色

右键顶部板标签 → 重命名；或颜色 → 红/橙/黄/绿/蓝/紫/灰。

说明：超过两个自定义板时标签区横向滚动。

U23删除收藏板

右键板标签 → 删除收藏板。

说明：只删除板及成员关系，不直接删除原始历史条目；目前没有专门确认弹窗。

U24调整置顶顺序

切换列表视图，在没有搜索词时拖动置顶条目。

说明：只提供置顶列表拖动排序；卡片收藏板尚无拖动排序入口。

U25编辑文本内容

卡片右键 → 编辑；或列表预览工具条 → 编辑。修改后点保存/完成，或 ⌘Return。

说明：当前是纯文本编辑器。修改富文本正文会丢失富文本格式并提示；不是 Paste 的富文本格式工具条。

U26修改别名与固定快捷键

卡片编辑窗顶部滑杆按钮打开属性；可修改非图片别名，置顶条目还可选择固定快捷键。

说明：图片别名字段禁用；非文本图片/文件不能修改正文。过长内容会禁用正文编辑。

U27新建文本

右上角更多 → 新建文本，输入内容，点创建或 ⌘Return。

说明：空白内容不能创建；创建同时把内容放进当前剪贴板，并按普通采集规则进入历史。暂停或隐私过滤仍可能影响采集。

U28删除单条记录

卡片/列表右键 → 删除，或选中后 ⌥Delete。

说明：单条删除没有确认弹窗；它会同时从所有收藏板移除，后续共享目录也不再包含该条。

暂停、清理与隐私

9 项
U29暂停记录

卡片更多 → 暂停剪贴板记录 → 暂停直到手动恢复；也可设置 → 高级（Advanced） → 暂停。

说明：暂停只影响新复制记录；原历史仍可浏览复制。⌥点击菜单栏图标也可切换。

U30只忽略下一次复制

卡片更多 → 暂停剪贴板记录 → 只忽略下一次复制；或 ⌥⇧点击菜单栏图标。

说明：跳过下一次检测到的剪贴板变化后自动恢复。

U31清除普通历史

卡片更多 → 清除历史记录，或设置 → 通用（General） → 清除历史记录，或 ⌥⌘Delete。

说明：保留置顶收藏和自定义收藏板成员；普通清除有确认，可选择不再提醒。

U32清除所有记录

卡片更多 → 清除所有记录（含收藏），或 ⌥⇧⌘Delete。

说明：会清除全部条目及板内成员，但保留空收藏板名称/颜色；需确认。

U33退出时清除

设置 → 高级（Advanced） → 退出时清除历史记录。

说明：退出时保留置顶收藏和自定义收藏板里的内容。设置页目前的提示只写了置顶，实际保留范围更大。

U34同时清除系统剪贴板

设置 → 高级（Advanced） → 同时清除系统剪贴板。

说明：开启后清除历史也会清除系统当前剪贴板。

U35忽略特定应用

设置 → 隐私（Privacy） → 应用程序 → ＋ 选择 App；选中后 － 删除规则。

说明：默认是拒绝名单；勾选忽略除列表外的所有应用则变为仅允许列表中的来源。

U36忽略剪贴板类型

设置 → 隐私（Privacy） → 剪贴板类型 → ＋，修改类型标识并回车；支持删除及重置默认。

说明：机密、临时、自动生成三类系统标记始终被忽略。可加入 com.apple.is-remote-clipboard 跳过通用剪贴板。

U37按正则排除内容

设置 → 隐私（Privacy） → 正则表达式 → ＋，编辑模式后回车；选中后 － 删除。

说明：匹配文字就不采集。无效正则会被忽略，当前没有显式格式错误提示。

设置与两种布局

13 项
设置入口：卡片右上角 … → 设置；列表底部 → 偏好设置；或在面板内按 ⌘,。左侧六页依次为 General（通用）、Agent、Privacy（隐私）、Shortcuts（快捷键）、Appearance（外观）、Advanced（高级）。当前安装版这些标签显示英文，卡片与 Agent 菜单仍为中文。
U38登录时启动

设置 → 通用（General） → 登录时启动。

说明：交给 macOS 登录项管理。

U39通知与声音

设置 → 通用（General） → 通知和声音右侧箭头。

说明：打开系统通知设置，不是在 App 内自定义音效。

U40默认复制或粘贴

设置 → 通用（General） → 粘贴方式，选复制到剪贴板或粘贴到当前应用。

说明：可另勾始终以纯文本粘贴；更改后可在快捷键页看实时修饰键说明。

U41历史数量与保存种类

设置 → 通用（General） → 保留历史设置 1–999 条（默认 200）；勾选文件、图像、文本。

说明：数量上限针对普通未收藏条目；置顶和自定义板成员被保留。取消某种类型只影响后续采集，不删除已有数据。

U42排序方式

设置 → 通用（General） → 排序方式，选上次复制、首次复制或复制次数。

说明：置顶顺序单独保存，不随普通排序变化。

U43更换快捷键

设置 → 快捷键（Shortcuts），录制打开、收藏/置顶、删除、显示预览四组快捷键。

说明：默认分别 ⌘⇧C、⌥P、⌥Delete、⌃Space；清空打开快捷键后仍可从菜单栏进入。

U44切换浅色深色

设置 → 外观（Appearance） → 配色，选浅色、深色或跟随系统。

说明：默认浅色，匹配参考截图。

U45切换卡片与列表

卡片更多 → 切换到列表视图；或设置 → 外观（Appearance） → 历史布局 → 卡片/列表。

说明：卡片提供收藏板、类型筛选和新建文本；列表保留更完整预览工具条和置顶拖动。

U46卡片出现屏幕

设置 → 外观（Appearance） → 显示器，选活跃屏幕或指定显示器。

说明：卡片固定在该屏幕底部，不能自由拖成任意位置。

U47列表位置与大小

列表模式下设置 → 外观（Appearance） → 弹出位置，选鼠标、菜单栏图标、当前窗口中心、屏幕中心、上次位置；拖动/调整窗口大小。

说明：上次位置支持重置；当前窗口中心可能依赖系统提供的窗口信息。

U48列表预览细节

列表模式下可设置顶在顶部/底部、图片高度 1–200、自动预览及延迟 200–100000 毫秒。

说明：默认图片高 40，自动预览打开，延迟 1500 毫秒；这些选项不会改变卡片尺寸。

U49菜单栏与标题显示

外观中可设置菜单栏图标及最近复制内容；列表模式还提供搜索框显示策略、搜索前标题和底部菜单设置。

说明：隐藏图标后可通过全局快捷键找回；隐藏列表底部菜单后用 ⌘, 打开设置。卡片模式隐藏不适用的列表选项，改为说明收起式搜索行为。

U50特殊符号、图标与色块

设置 → 外观（Appearance）切换换行/制表符标记、来源应用图标、十六进制颜色块。

说明：特殊符号主要用于条目标题；卡片正文按多行显示。

Agent 共享、云盘与简报

15 项
当前连接状态：Google Drive 已完成登录和真实上传核验；iCloud Drive 已连接本次走查的专用目录，本机副本一致，macOS 已确认上传完成；第二设备读取尚未验证。正式应用已恢复正常运行，保留这两个连接，共享方式为关闭。本机正式目录为 ~/Library/Application Support/ClipContext/Agent/clipboard.json，不再使用测试环境目录。需要分享资料时，再由你选择共享范围。Claude Code 的真实会话按你的要求跳过。
U51进入 Agent 设置

卡片更多 → Agent 目录；列表底部 → Agent 目录；或设置左侧 → Agent。

说明：默认共享关闭。

U52手动共享单条

右键历史 → 分享给 Agent；撤销时选撤销 Agent 共享。

说明：第一次手动分享会将关闭改为手动选择；被隐私规则拒绝的条目不可共享。

U53选择共享范围

Agent → 共享方式：关闭、手动选择、收藏与手动选择、所有历史。

说明：选择所有历史需再次确认；单条撤销优先于该范围。这里的「收藏」只指内置置顶收藏；自定义收藏板中的内容需另行手动分享。

U54同步频率与立即同步

Agent → 同步间隔选 1/5/15/60 分钟；点立即同步查看写入条数与时间。

说明：默认 5 分钟；修改共享策略也会触发同步，程序需保持运行。目录是最新快照，不是无限期日志。当前正式应用保留 Google Drive 与 iCloud Drive 连接，共享方式为关闭；重新选择共享范围后才会发布相应内容。

U55查看本机目录

Agent → 本机目录 → 在 Finder 中显示。

说明：路径 ~/Library/Application Support/ClipContext/Agent/clipboard.json；成功首次写入前按钮禁用。

U56连接 iCloud Drive连接设置

Agent → iCloud Drive → 选择文件夹，选择 iCloud Drive 内目录。

能力与授权边界

  • 收藏与收藏板不同。内置“收藏”会固定条目；自定义收藏板只是分组。Agent 的“收藏与手动选择”不会自动包括自定义板里的所有内容。
  • 同步目录与生成简报是两件事。应用定时更新共享资料；调用 Codex 或 Claude Code 生成简报，还需登录并另外设置定时任务。
  • 云盘是每台设备的单向目录副本。当前不从云端恢复或合并剪贴板历史，也不自动同步收藏板结构。复制的本地文件只共享引用，不备份原文件。
  • 撤销只影响后续共享。关闭共享并同步后，当前目录会变为空；Agent 已读入的会话、下载副本和旧简报不会被自动收回。
  • 敏感内容依赖来源标记与规则。会跳过机密、临时、自动生成标记以及你配置的忽略规则，但没有通用的“识别所有敏感文字”保证。
  • 直接粘贴需要系统权限。若选择后只复制了内容、没有自动粘进另一应用，先检查系统设置 → 隐私与安全性 → 辅助功能。0.1.1 会显示权限说明和设置入口，最终授权仍需你在 macOS 完成，授权后重新操作。
  • 部分功能只在列表里。图片识别文字的复制、置顶拖动排序和自动预览侧栏，当前需要列表视图。多选与顺序粘贴同时支持卡片和列表，入口及权限见 U67。
  • 编辑是纯文本编辑。改动富文本正文会去掉格式。没有参考 Paste 中的订阅、Apple Intelligence 和富文本格式工具条。
  • 卡片与列表的设置范围不同。“始终显示搜索框”和搜索前应用名仅在列表模式提供。卡片模式使用收起式搜索，并显示相应说明。
  • 终端命令使用本应用设置域。正式版为 com.benzema.ClipContext；高级页现按运行中的应用标识生成命令。忽略下一次需要同时启用两项设置，见技术附录。

MCP 与简报参数

Google OAuth 客户端首次创建时请保存配置。已有客户端的旧 secret 若无法重新显示或下载，可在 Google Cloud 客户端页面选择 Add secret；由用户本人将新 secret 填到 ClipContext，不能在聊天、日志或共享文档中传递它。
使用 Agent 页按钮复制当前安装位置生成的命令，避免手工写错脚本路径。MCP 的 recent/search 默认返回 15 条，最多 50 条；get 的文本每页上限 8000 字符。recent/search 的时间参数需要时区，来源筛选使用精确的应用 bundle ID。

recent: since, application, limit, offset, afterRevision
search: query, since, application, limit, offset
get: id, textOffset, includeImage

简报命令可追加：
--preview           只查看待处理数量
--batch-size 30     每批处理数量（1–150）
--model <模型名>    选择可用模型

简报需调用真实、已登录的 CLI。模型失败或空输出不会推进进度；旧快照会被拒绝；重复并发运行有锁。命令注册本机 MCP，不会自动建立云端访问授权。

云端与本机核验边界

上版于 2026-11-12 核对安装包附带的 MCP/简报脚本并完成真实远端核验，以下是历史证据，不代表 0.1.1 已完成全部测试：共享 2 条（revision 3）→ 撤销后 1 条（revision 4）→ 关闭共享后 0 条（revision 5），三次远端下载均与本地 JSON 逐字节一致。云端测试文件标识未包含在项目包中。iCloud 已连接 用户选择的 iCloud Drive 测试目录；上版核验时 revision 5 的空目录为 132 字节，与本机目录逐字节一致，macOS 显示已上传、当前版本且无上传错误；尚未做独立云端下载或第二设备读取，因此不能据此声称另一设备已经收到。上版验收使用两条独立样例成功生成真实 Codex CLI 简报，随后预览确认无待处理变更；也通过仅用于当次进程的临时配置，成功完成了一次真实 Codex MCP recent 读取。两种能力均已在合成资料上验证，但没有永久注册或修改你的 MCP 配置。Claude Code 实际会话按用户要求跳过。
