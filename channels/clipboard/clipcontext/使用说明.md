# ClipContext 使用说明

适用版本：**0.1.1（2）**

ClipContext 是 macOS 剪贴板管理应用。它可以保存复制过的文字、富文本、图片和文件引用，帮助你搜索、收藏、编辑并再次取用；你也可以主动选择资料，提供给本机或已获授权的 Agent 读取。

**默认只在本机管理历史，Agent 共享默认关闭。** 登录云盘、接入 Codex 或 Claude Code 都是可选步骤，不影响日常剪贴板功能。

## 安装与第一次使用

### 安装和启动

1. 解压安装 ZIP，将其中的 `ClipContext.app` 拖到 Mac 的“应用程序”文件夹。**本次分发包适用于 Apple Silicon（arm64）Mac，不是兼容 Intel 的通用包**；应用要求 macOS 14 或以上。
2. 双击打开。ClipContext 是菜单栏应用，启动后通过屏幕顶部的菜单栏图标使用，不会一直显示主窗口。
3. 如果已经运行旧版，先从应用菜单退出旧版，再替换应用。替换应用文件与清除历史是不同操作，不需要为了更新而删除本地数据。
4. 如需开机后自动使用，打开 **设置 → 通用（General）→ 登录时启动**。

首次打开若被 macOS 拦截，请核对安装包来源，并按照系统“隐私与安全性”页面提供的提示处理；不需要关闭系统整体安全保护。

### 三步开始使用

1. 保持 ClipContext 运行，在其他应用正常复制一段文字、图片，或在 Finder 中复制文件。
2. 点菜单栏图标，或按默认快捷键 **⌘⇧C** 打开历史。
3. 点击一条历史，或选中后按 **Return**；回到目标应用按 **⌘V**。

默认行为是把历史内容重新放回剪贴板。若希望选择后直接粘进原应用，请阅读[复制与粘贴](#use-content)及[辅助功能授权](#data)。普通采集、搜索和手动复制不要求你先接入云盘或 Agent。

按 **Esc** 或点击面板外可关闭历史。面板有焦点时按 **⌘,** 打开设置。卡片右上角的“更多”菜单中也有设置、使用指南、关于和退出入口。

界面文字会随系统语言变化，部分新增菜单显示中文；下文同时标出主要设置页的英文名称。

## 卡片视图与经典列表

两种布局使用同一份历史，切换布局不会另建资料库。

| 布局 | 适合的操作 | 主要特点 |
| --- | --- | --- |
| 卡片 | 横向浏览、图片与链接预览、收藏板整理 | 显示在屏幕底部，支持收藏板、类型筛选和新建文本 |
| 经典列表 | 键盘取用、置顶拖动排序、完整预览工具条 | 可调整窗口位置和大小，支持预览侧栏及图片识别文字的复制入口 |

切换方式：**卡片更多 → 切换到列表视图**，或 **设置 → 外观（Appearance）→ 历史布局**。

卡片可以横向滚动；搜索词为空且没有输入法候选时，可用左右方向键切换卡片。输入搜索词后，左右方向键用于编辑文字。面板不会把输入法组合输入中的按键强行当作导航。

卡片固定在所选显示器底部；可在外观设置中选择活跃屏幕或指定显示器。经典列表则支持鼠标位置、菜单栏图标、当前窗口中心、屏幕中心和上次位置等弹出位置。

<a id="use-content"></a>
## 复制、粘贴与内容预览

### 自动保存什么

应用运行时会检查新的剪贴板变化，默认检查间隔为 0.5 秒。它不会主动导入启动前一直未变化的剪贴板内容；需要时再复制一次即可。

支持文字、RTF/HTML 等富文本、图片和文件引用。可在通用设置中选择保存文件、图像、文本中的哪些类型。关闭某类采集只影响后续记录，不删除已有内容。

同一内容再次复制会更新对应记录的时间或次数。相同文字但格式真正不同的内容可能保留为不同记录。

### 三种取用方式

以下按默认设置说明，均以**单选状态**为前提。

| 想做什么 | 操作 | 结果 |
| --- | --- | --- |
| 复制回剪贴板 | 点击条目，或按 Return | 回到目标应用后自行按 ⌘V |
| 直接粘贴 | ⌥Return、⌥点击，或卡片右键 → 粘贴 | 尝试把内容插入原先的前台应用，需要辅助功能权限 |
| 去格式粘贴 | ⌥⇧Return、⌥⇧点击，或卡片右键 → 粘贴为纯文本 | 使用条目的纯文本表示，需要辅助功能权限 |

纯文本操作要求该条目本身具有纯文本表示。图片和文件不会因此自动转成文字；卡片菜单会禁用不适用的纯文本操作。图片识别文字使用下方的独立入口。

可以在 **通用 → 粘贴方式** 修改默认复制/直接粘贴行为，或开启始终以纯文本粘贴。修改后，修饰键组合也会变化，请以 **快捷键（Shortcuts）** 页的实时说明为准。

普通历史带有数字快捷键，置顶收藏可使用固定字母快捷键。打开面板后按条目显示的组合即可取用；卡片的快捷键提示会在按下相应修饰键时出现。

多选模式中的点击用于增减选择，Return 用于启动队列；需要单独取用某一项时，可使用该项右键菜单或先取消多选。

### 预览、链接、文件和颜色

- **查看完整内容**：卡片右键 → 预览，或选中后按 ⌃Space。经典列表可使用预览侧栏按钮。
- **查看信息**：预览提供文字或图片，以及来源应用、首次/最近复制时间和复制次数。
- **链接**：完整的 `http://` 或 `https://` 地址会显示为链接卡片。它展示域名、路径和通用浏览器图标，不会抓取网页正文或封面。
- **文件**：Finder 复制的文件显示文件名与类型图标。应用保存文件引用，不会把原文件内容备份进历史或上传云盘。
- **图片**：卡片显示缩略图及尺寸。
- **颜色值**：支持的十六进制颜色文字可显示色块；来源应用图标和色块可在外观中开关。

### 复制图片里的文字

切换到**经典列表**，选中图片并打开预览侧栏，点击文字识别图标。按钮会把已识别出的文字复制到剪贴板；没有识别结果时禁用。

当前卡片预览没有这组工具条，需使用列表入口。识别结果取决于图片文字是否清晰，不保证所有图片都能识别。

<a id="search"></a>
## 搜索与类型筛选

卡片顶部点击放大镜展开搜索；点击清除按钮可清空关键词。展开搜索时，收藏板名称会收为图标，新增收藏板的“＋”暂时隐藏。

搜索框右侧的筛选按钮可选择：**全部类型、文本、链接、图像、文件**。搜索结果同时受以下三个条件影响：

1. 当前范围：全部剪贴板、内置收藏或某个自定义收藏板。
2. 类型筛选。
3. 搜索关键词。

没有结果时，先清空关键词，再恢复“全部类型”，最后检查是否停留在某个收藏板中。

在 **通用 → 搜索** 可选择精确、模糊、正则或混合搜索。精确搜索实际是不区分大小写的子串匹配；界面主要搜索条目的标题，标题可能来自别名或图片识别文字，不等于检索所有附件的原始数据。

在 **外观 → 匹配文本高亮** 中可选择粗体、斜体、下划线或颜色。高亮作用于列表或文字卡片的匹配标题。

搜索编辑快捷键：**⌃U** 清空、**⌃H** 删除最后一个字符、**⌃W** 删除最后一词。输入法候选未确认时，先完成文字输入。

<a id="collections"></a>
## 收藏与收藏板

### 内置“收藏”：固定常用内容

右键卡片选择“收藏/取消收藏”，或选中条目按 **⌥P**。顶部的“收藏”标签只显示这些置顶条目。置顶条目可配置固定字母快捷键。

调整置顶顺序：切换经典列表，清空搜索词后拖动置顶条目。置顶顺序独立于普通历史的排序方式。

### 自定义收藏板：按主题分组

1. 点击卡片顶部 **＋**，输入非空名称并保存。
2. 右键一条卡片 → **加入收藏板** → 选择目标板。
3. 再次点击菜单中已勾选的板，可将这条内容移出该板。

同一条内容可以加入多个板。新板默认被选中；板较多时可横向滚动标签区。

右键板标签可重命名、选择红/橙/黄/绿/蓝/紫/灰颜色，或删除该板。**删除收藏板只删除分组及成员关系，不直接删除历史内容；当前没有单独确认弹窗。** 卡片收藏板目前没有拖动排序入口。

内置收藏与自定义收藏板不是同一概念。加入自定义板不会自动置顶，也不会自动分享给 Agent；共享方式中的“收藏与手动选择”仅自动包括内置置顶收藏。

<a id="editing"></a>
## 新建、编辑与删除

### 新建文本

卡片右上角 **更多 → 新建文本**，输入内容后点“创建”或按 **⌘Return**。空白内容不能创建。

创建会把文本放入当前剪贴板，再按正常采集规则进入历史。如果正在暂停或命中隐私过滤规则，历史可能不会新增该条。

### 修改内容、别名和快捷键

卡片右键 → **编辑**，或使用列表预览工具条的编辑按钮。修改后点保存/完成，或按 **⌘Return**。

编辑窗中的属性按钮可修改非图片条目的别名；置顶条目还可配置固定快捷键。图片不能修改别名，非文本图片或文件不能编辑正文；过长的内容可能禁用正文编辑。

**正文编辑器是纯文本编辑器。** 修改富文本正文会丢失原格式，应用会给出提示。若只想为内容起一个便于搜索的名字，优先修改别名。

### 删除记录

右键条目 → **删除**，或选中后按 **⌥Delete**。单条删除没有确认弹窗；记录也会从各收藏板移除，之后的共享快照不再包含它。删除正在使用的队列条目会停止队列。

<a id="paste-queue"></a>
## 多选与顺序粘贴

适合依次填写多个字段、连续插入几段文字等场景。队列会按你的选择顺序准备条目。

1. 在卡片“更多”菜单或经典列表顶部点击 **选择多条…**。进入时保留当前高亮项。
2. 点击其他条目加入选择，再次点击可取消。查看已选数量及条目编号，确认顺序。
3. 点击 **开始顺序粘贴**，或按 **Return**。此时准备第一条内容，**不会自动插入第一条**。
4. 回到目标应用，把光标放在需要的位置，按一次 **⌘V** 粘贴第一条。
5. 移到下一个位置，再按 **⌘V**；每次完成一次粘贴后，队列准备下一条。

也可以用 **⌘点击** 进入或增减多选。经典列表用 **⇧↑ / ⇧↓** 扩展选择；卡片在空搜索且无输入法候选时用 **⇧← / ⇧→** 扩展选择。

队列需要辅助功能权限，以识别外部粘贴操作。缺权限时不会启动队列；完成系统授权后，请重新选择条目并启动。当前默认取用/去格式设置会影响队列的内容格式，开始后不会中途随设置切换。

面板会显示剩余条目和停止入口；不想继续时点击停止。以下操作也会停止队列：外部应用复制了新内容、单独取用其他历史、清空历史，或删除队列中的项目。不要在队列执行中穿插其他复制操作；需要时停止后重新选择。

“取消多选”退出选择模式，不删除历史。顺序粘贴与把多条内容合并为一段是不同功能，当前队列每次只准备一条。

<a id="privacy"></a>
## 暂停、清理与隐私规则

### 暂停与恢复

- **一直暂停**：卡片更多 → 暂停剪贴板记录 → 暂停直到手动恢复；也可在高级设置中控制，或 **⌥点击菜单栏图标** 切换。
- **只忽略一次**：同一菜单选择“只忽略下一次复制”，或 **⌥⇧点击菜单栏图标**。跳过下一次检测到的剪贴板变化后自动恢复。

暂停只影响新内容采集，已有历史仍可浏览和复制。暂停采集不会自动关闭 Agent 共享；要停止发布已有内容，应另行关闭共享。

### 清理时哪些内容会保留

| 操作 | 入口 | 保留范围 |
| --- | --- | --- |
| 清除普通历史 | 卡片更多 → 清除历史记录；通用设置；⌥⌘Delete | 保留置顶收藏和自定义收藏板成员 |
| 清除所有历史 | 卡片更多 → 清除所有记录（含收藏）；⌥⇧⌘Delete | 删除全部记录及板成员，保留空收藏板名称和颜色 |
| 退出时清除 | 高级 → 退出时清除历史记录 | 保留置顶收藏和自定义板内记录 |
| 同时清除系统剪贴板 | 高级 → 同时清除系统剪贴板 | 开启后，清理历史时也清除系统当前剪贴板 |

清理操作会显示确认；若选择过“不再提醒”，后续可能直接执行。经典列表中的“清空”在按住 Shift 时切换为“清空全部”，操作前留意文字。

### 忽略某些来源或内容

打开 **设置 → 隐私（Privacy）**：

- **应用程序**：用“＋”加入不希望采集的 App，“－”删除规则。勾选“忽略除列表外的所有应用”后，列表变为允许来源名单。
- **剪贴板类型**：用“＋”添加类型标识，编辑后按回车；可删除或重置默认项。加入 `com.apple.is-remote-clipboard` 可忽略通用剪贴板来源。
- **正则表达式**：添加需要排除的文字模式，编辑后按回车。匹配的文字不采集；无效表达式会被忽略，当前不会明确提示正则语法错误。

机密、临时和自动生成等特定剪贴板标记会被忽略。是否带有这些标记取决于来源应用；ClipContext 不保证自动识别所有密码、验证码或其他敏感文字。配置规则只影响相应采集/共享判断，不会替你清理过去已经保存或已被其他程序读取的副本。

### 可选：用终端暂停

高级设置提供按当前应用标识生成的命令。正式 ClipContext 的命令如下，不需要用于普通日常操作：

```sh
# 暂停记录
defaults write com.benzema.ClipContext ignoreOnlyNextEvent -bool false
defaults write com.benzema.ClipContext ignoreEvents -bool true

# 恢复记录
defaults write com.benzema.ClipContext ignoreOnlyNextEvent -bool false
defaults write com.benzema.ClipContext ignoreEvents -bool false

# 只忽略下一次复制，然后自动恢复
defaults write com.benzema.ClipContext ignoreOnlyNextEvent -bool true
defaults write com.benzema.ClipContext ignoreEvents -bool true
```

<a id="settings"></a>
## 设置项目

入口为卡片更多 → 设置、列表底部 → 偏好设置，或面板内 **⌘,**。

| 页面 | 可以调整的内容 |
| --- | --- |
| 通用 General | 登录启动、系统通知入口、默认复制/粘贴、始终纯文本、搜索方式、历史数量、保存类型、排序及清除历史 |
| Agent | 共享范围、同步频率、本机目录、iCloud、Google Drive、MCP 与简报命令 |
| 隐私 Privacy | 忽略应用、剪贴板类型和正则表达式 |
| 快捷键 Shortcuts | 打开面板、收藏、删除、预览的快捷键，以及当前修饰键说明 |
| 外观 Appearance | 卡片/列表、配色、显示器、窗口位置、预览、菜单栏和文字显示 |
| 高级 Advanced | 暂停、忽略下一次、退出清理、清系统剪贴板及终端命令 |

常用细节：

- **历史数量**：可设 1–999 条，默认 200。数量限制针对普通未收藏记录；置顶与自定义板成员会保留。
- **排序**：按最近复制、首次复制或复制次数排列；置顶顺序单独保存。
- **配色**：浅色、深色、跟随系统，默认浅色。
- **通知和声音**：通过通用页打开 macOS 的系统通知设置，不是在应用内选择自定义音效。
- **快捷键**：打开面板、收藏、删除、预览四组可更改。清空打开快捷键后仍可点菜单栏图标进入。
- **菜单栏**：可设置图标及最近复制内容显示。隐藏图标前请保留可用的全局快捷键。
- **文字显示**：可切换换行/制表符标记、来源应用图标、颜色色块及搜索匹配样式。

经典列表额外支持：置顶位于顶部或底部、图片高度 1–200（默认 40）、自动预览及延迟（默认 1500 毫秒）、搜索框显示策略、搜索前应用名、底部菜单、窗口位置与尺寸。隐藏底部菜单后仍可按 ⌘, 打开设置；使用“上次位置”时可重置位置。

这些列表专用选项不会改变卡片尺寸或收起式搜索行为，在卡片模式下会隐藏或显示相应说明。

<a id="sharing"></a>
## 选择要共享给 Agent 的资料

共享会建立一份可供 Agent 读取的目录快照。**初始状态为关闭，不会因为安装应用就把全部剪贴板交给 Agent。**

入口：卡片更多 → Agent 目录、列表底部 → Agent 目录，或设置左侧的 Agent 页。

| 共享方式 | 包括哪些记录 |
| --- | --- |
| 关闭 | 不继续共享历史；曾共享过时可同步为空目录 |
| 手动选择 | 你逐条选择分享的记录 |
| 收藏与手动选择 | 内置置顶收藏，以及逐条手动分享的记录 |
| 所有历史 | 当前和后续采集的历史；切换时需要确认 |

右键一条历史 → **分享给 Agent**。第一次这样操作会把“关闭”切换为“手动选择”。右键选择 **撤销 Agent 共享** 可排除该条，单条撤销优先于整体共享范围。被隐私规则拒绝的内容不能共享。

**自定义收藏板不等于共享名单。** 即使选择“收藏与手动选择”，自定义板成员也需要另行分享，除非它同时是内置置顶收藏。

同步间隔可选 1、5、15、60 分钟，默认 5 分钟；也可以点 **立即同步**。共享策略变化会触发更新，应用需保持运行。页面会显示本机写入条数、时间及错误信息。首次未选择共享且没有旧目录时，立即同步可能不可用。

共享目录可能包含选中记录的文字、富文本或图片数据、来源应用及复制时间。文件条目只含引用，不能用于备份原文件。不要把不希望 Agent 或所连接云盘接收的内容放入共享范围。

成功写入后，可点 **本机目录 → 在 Finder 中显示**。该目录始终是最新快照，不是无限期的事件日志。

### 撤销或停止共享

撤销单条、删除历史或关闭共享后，变更在后续成功同步中反映到目录及已连接的云盘。关闭共享并同步空目录，可检查写入条数确认结果；同步报错时应先处理错误。

撤销不会自动删除 Agent 已读入的会话、另存的文件或过去的简报。停止采集、停止共享、断开云盘是三个独立操作。

<a id="cloud"></a>
## Google Drive 与 iCloud Drive

两者都是可选的同步位置。你可以只使用本机目录，也可以连接其中一个或两个。

**云端保存的是每台设备发布的单向快照。** 当前不会从云端恢复或合并历史，不会同步恢复收藏板结构，也不等于文件原件备份。另一台设备能否读取，还取决于云盘同步状态及该设备的账号和读取权限。

### 连接 iCloud Drive

1. 先在 macOS 登录自己的 Apple 账户并启用 iCloud Drive。
2. 在 **Agent → iCloud Drive → 选择文件夹…** 中，选择 iCloud Drive 内的一个文件夹。
3. 选择共享范围，点立即同步，查看页面状态；也可到 Finder 检查云盘同步状态。

应用会在所选文件夹中写入 `ClipContext/<设备ID>/clipboard.json`，再由 macOS 负责同步。本机成功写入不等于另一台设备已收到。

断开或更换目录会移除原位置属于本设备的快照。请先确认是否还需保留该副本。

### 连接 Google Drive

当前版本需要你自己的 Google Cloud OAuth 客户端配置：

1. 在 **Agent → Google Drive → 连接…** 中，点击打开 Google Cloud OAuth 客户端的入口。
2. 在自己的项目启用 Drive API，并准备 **Desktop app** 类型的 OAuth 客户端及所需授权配置；若项目处于测试模式，需将登录账号加入允许的测试用户。
3. 将客户端 ID 和客户端密钥填入 ClipContext 的对应框，点击 **在浏览器中授权**。
4. 保持 ClipContext 运行，在浏览器选择账号并确认授权；浏览器回传完成后，回到应用查看连接状态。
5. 选择共享范围并同步，查看上传时间。首次成功上传后可点击 **打开副本**。

客户端密钥只填写在应用的密钥框中，不要放进聊天、截图或 Bug 附件。登录凭证保存在系统钥匙串。若无法取得旧客户端密钥，请在自己的 Google Cloud 项目中按其凭证管理流程准备可用配置。

Google 副本按设备保存为 `ClipContext-<设备ID>.json`。**断开 Google Drive 不会删除云端最后一份文件。** 若要撤回当前副本，可先关闭共享并成功同步为空目录，或自行在 Google Drive 删除对应文件；旧下载和已读入的 Agent 会话仍需分别处理。

授权页若显示 `127.0.0.1` 拒绝连接，通常表示本次本地回传会话已不再监听。不要反复刷新过期的回传地址；回到仍在运行的 ClipContext，从连接入口重新发起授权，并查看应用内错误提示。

<a id="agents"></a>
## MCP、Codex 与 Claude Code

MCP 是让 Agent 按需读取共享目录的接口。ClipContext 提供只读查询，不会因为启用 MCP 就允许 Agent 修改你的剪贴板历史。

### 接入本机客户端

1. 自行安装并配置可用的 **Codex CLI** 或 **Claude Code CLI**，完成该工具需要的登录、账号和计费配置；同时准备可用的 Python 3 运行环境。
2. 先在 ClipContext 选择共享资料，确认本机目录已成功写入。
3. 在 Agent 页点击 **复制 Codex 命令** 或 **复制 Claude Code 命令**。
4. 把命令粘到终端执行，检查终端结果；随后打开新的 Agent 会话使用。

“复制命令”只复制文本，不会自动执行安装或注册，也不会自动替 CLI 登录。命令根据当前应用安装位置生成；如果移动过应用或重新安装，请从 Agent 页重新复制，避免使用旧路径。生成的命令使用 `/usr/bin/python3`；若本机缺少该解释器，请先配置运行环境。

**Claude Code 需由你自行配置和登录。** 安装 ClipContext 不包含 Claude 或 Codex 的模型使用权益，也不保证任意账号都已具备所需访问能力。

### 可以怎样查询

可以对 Agent 说：

> 用 clipcontext 查找我今天主动共享的链接，先列出条目 ID，再读取我指定的一条。

| 工具 | 用途 |
| --- | --- |
| `recent` | 按最近复制时间列出共享条目摘要 |
| `search` | 检索共享条目的摘要和文字 |
| `get` | 按 ID 读取条目，长文本可分页，图片需显式请求 |

列表查询支持时间、来源和分页；默认 15 条，最多 50 条。单次读取的文本页上限为 8000 字符。来源条件使用应用标识，时间条件需带时区。文件条目只返回引用，不读取引用文件的正文。

MCP 只能看到共享目录中的内容。应用未运行、未共享或快照长时间未更新时，Agent 可能看不到新资料；请先检查 Agent 页的同步状态。

### 让云端 Agent 读取

本机 MCP 注册命令只连接本机客户端，不会自动把服务开放到互联网，也不会替云端 Agent 授权 Google Drive 或 iCloud。

云端 Agent 需要使用你另行授权的云盘连接器或文件读取方式访问副本。使用托管模型时，实际读取的文字或图片可能进入模型上下文；共享目录不是自动授权所有 Agent 访问你全部生活资料的开关。

<a id="digest"></a>
## 生成简报与定时运行

Agent 页的 **复制简报命令** 可以选择“用 Codex 生成”或“用 Claude Code 生成”。复制到终端后执行，前提是对应 CLI 已可正常调用。

简报按上次成功进度处理新增、变化及撤销的条目。默认每批 30 条，可设 1–150 条；每条正文最多取前 1200 个字符，因此简报不是原文完整备份。无变化时不会重复调用模型；调用失败或结果为空时不推进进度。Codex 与 Claude Code 分别记录处理进度。

可以在复制出的命令末尾追加：

```text
--preview          只看待处理数量，不调用模型，不推进进度
--batch-size 30    设置本次处理条数，范围 1–150
--model <模型名>   使用自己账号可访问的模型
```

成功生成的简报保存在 `~/Library/Application Support/ClipContext/Reports`。旧简报不会因之后撤销共享而自动删除。

若希望周期生成，先手动运行成功，再把同一命令加入自己配置的 Agent 定时任务或本机调度。**Agent 页的“同步间隔”只更新资料，不会自动运行模型。** 生成简报的定时计划需另外设置；应用也需运行，才能持续更新输入资料。

<a id="data"></a>
## 数据位置、备份与授权

### 本地数据

以下 `~` 代表当前用户的主目录，不需要替换成某个特定用户名。

| 内容 | 默认位置或保存方式 |
| --- | --- |
| 历史数据库 | `~/Library/Application Support/ClipContext/History.sqlite` |
| Agent 共享快照 | `~/Library/Application Support/ClipContext/Agent/clipboard.json` |
| 简报 | `~/Library/Application Support/ClipContext/Reports` |
| 应用偏好与收藏板信息 | macOS 的 ClipContext 应用偏好 |
| Google 登录凭证 | macOS 系统钥匙串 |

需要保存本地历史副本时，先退出应用，再备份整个 `~/Library/Application Support/ClipContext` 文件夹，避免只复制正在写入的数据库主文件。这个文件夹不包含全部系统偏好和钥匙串凭证；当前没有一键完整备份/恢复工具，云端 JSON 也不能替代完整备份。

删除应用文件不等于删除历史、云端副本、钥匙串凭证或已生成简报。若准备停止使用并撤回资料，应分别处理共享、云端副本和本地数据。

### 辅助功能权限

直接粘贴和顺序粘贴需要 macOS 辅助功能权限；普通历史采集、查找和“复制后手动 ⌘V”可独立使用。

缺权限时，应用会显示解释并提供“打开系统设置”入口。按提示进入 **系统设置 → 隐私与安全性 → 辅助功能**，由你开启 ClipContext；macOS 可能要求密码或 Touch ID。

应用不能替你开启系统开关。授权不会自动重放刚才的粘贴动作：请重新发起粘贴；顺序粘贴则重新选择条目并开始队列。选择“稍后”时，普通粘贴操作已复制的内容仍可手动按 ⌘V 使用。

更新后若系统显示已授权，但应用仍提示未授权，可先退出并重新打开，检查系统列表中的条目是否对应当前安装位置，按系统提示重新授权。不要同时运行多份安装副本。

通知、登录启动、云盘连接和 CLI 登录都是各自独立的设置。开启辅助功能不会自动开启共享或登录云盘。

<a id="faq"></a>
## 常见问题与当前限制

### 打开应用后找不到窗口

先看菜单栏图标，或按 ⌘⇧C。若曾隐藏图标，用自己设置的全局快捷键进入外观设置恢复。不要同时隐藏图标并清空唯一打开快捷键。

### 新复制的内容没有出现

确认应用正在运行，检查是否暂停、只忽略一次、未保存该类型、来源 App 被忽略或文字命中正则；也检查当前搜索、类型筛选及收藏板范围。应用启动前未变化的剪贴板可再复制一次。

### 点击后没有直接粘进目标应用

默认点击只复制。回到目标应用按 ⌘V，或使用直接粘贴操作。若选择的是直接粘贴，检查辅助功能授权、目标输入框焦点和默认取用设置；完成授权后需重新操作。

### 顺序粘贴只得到一条，或突然停止

确认是在多选状态启动了队列，并在目标应用逐次按 ⌘V。启动不会自动插入首项；外部复制、另选历史、清除或删除队列项目会停止队列。检查剩余数量，必要时重新选择并开始。

### 想要完整富文本，但格式不见了

检查是否启用了始终纯文本或使用了去格式组合。正文编辑本身也会去格式。接收应用可能不支持原格式；有些来源内容只有纯文本表示。

### 收藏板里的条目没有自动共享

自定义收藏板只是整理分组。右键选择“分享给 Agent”，或把需要自动纳入的条目设为内置收藏并选择相应共享方式。

### 本机目录写入成功，云端或 Agent 仍没有新资料

分别检查上传状态、账号连接及 Agent 的读取权限。iCloud 还需等待系统完成上传。本机 MCP 只读取本机目录，云端 Agent 需另行授权；注册完成后打开新会话。应用退出后不会继续更新快照。

### 简报命令报错或没有生成新报告

先确认对应 CLI 已安装、登录并可调用模型，Python 路径可用，复制出的应用路径仍有效。用 `--preview` 查看是否有变化；没有变化不生成重复简报。同步目录的间隔不会自动触发简报命令。

### 为什么部分选项只在列表里

图片识别文字的复制、置顶拖动排序、自动预览侧栏及列表搜索框显示策略属于经典列表。卡片使用固定尺寸和收起式搜索；切换到列表即可使用相关入口。

### 当前没有提供哪些能力

当前没有云端历史恢复/合并、自定义收藏板跨设备恢复、文件原件备份、网页正文抓取、卡片拖入其他应用、富文本格式编辑工具条、订阅管理或 Apple Intelligence 专用页面。自动采集与隐私规则也不等于保证识别所有敏感内容。

如有问题，请阅读同目录的 [Bug反馈说明](<Bug 反馈说明.md>)，提供复现步骤和必要截图；发送前先去掉私人剪贴板内容、账号信息和密钥。
