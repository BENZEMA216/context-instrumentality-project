# Agent 接入

在 iPhone 打开「同步 → 保存到」，选择已连接的 Google Drive 或 iCloud Drive。展开「Agent 接入说明」，点击「复制给 Agent」，把说明交给你选择的工具。

授权范围由用户与云盘决定。Agent 通过已有的云盘连接访问所选目录，根据录制时间、片段序号和清单定位录音，可先读已有转写，再按用户需求转写相关音频。需要将音频交给云端转写服务时，先确认服务和范围。
